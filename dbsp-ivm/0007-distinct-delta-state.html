Distinct 的增量：只在 0 边界输出

教程制作 · 李金懋（OceanBase）

本课处理非线性算子 distinct：输入权重可以连续变化，但输出只在记录的存在性跨越 0 边界时改变；高效实现必须维护每个记录的输入计数。

依据：DBSP 论文 Definition 4.3（distinct）与 Proposition 4.7（增量电路与 H）。

1. 问题：相同的 −A，为什么产生不同的输出？

只跟踪一条记录 A。初始快照为空，四批输入变化依次是 +A, +A, −A, −A。视图定义为 Vt = distinct(Xt)。先逐批计算完整快照与正确的视图变化。

观察：正确增量是 +A, ∅, ∅, −A。t = 3 与 t = 4 收到完全相同的 −A，前者不输出，后者却要撤回 A。唯一差别是应用变化前，A 的权重分别为 2 和 1。

由此得到本课要解决的问题：如何把“旧权重 + 本批变化”转换为正确的 distinct 输出变化，并把所需旧权重放进增量电路。

2. 从观察得到 distinct 的定义与非线性

上表中，基表权重从 1 变到 2 时，视图仍是 {A↦1}：任意正权重都被压成 1。权重从 2 降到 1 时，视图仍然不变；只有从 1 降到 0 时，视图才撤回 A。

把这个行为写成快照算子。令 X 是输入 Z-set，X(x) 表示记录 x 的整数权重。则：

distinct(X)(x) = 1，若 X(x) > 0 distinct(X)(x) = 0，若 X(x) ≤ 0

输出仍是 Z-set，但每个记录的权重只取 0 或 1。权重 ≤ 0 的记录不出现在输出中。

现在检查能否把旧输入与本批变化分开计算。取 P={A↦1}、D={A↦1}：

distinct(P + D) = distinct({A↦2}) = {A↦1} distinct(P) + distinct(D) = {A↦1} + {A↦1} = {A↦2}

先合并再计算，与分别计算后相加不相等。因此 distinct 不保持 Z-set 加法，是非线性算子；不能使用线性化简 (↑distinct)Δ = ↑distinct。这也解释了为什么只执行 distinct(dt) 不能得到第 1 节的正确变化。

3. 从新旧结果之差推出逐记录判别规则

设一批变化开始前的输入为 i，本批变化为 d，则新输入为 i+d。按照视图变化的定义，本批必须输出：

ΔV = distinct(i+d) − distinct(i)

对任意记录 x，distinct 只判断权重是否大于 0。因此：

ΔV(x) = [ (i+d)(x) > 0 ] − [ i(x) > 0 ]

方括号内条件成立时取 1，否则取 0。比较新旧两个判断，只可能得到三种输出：

H(i, d)(x) = −1，若 i(x) > 0 且 (i + d)(x) ≤ 0 H(i, d)(x) = +1，若 i(x) ≤ 0 且 (i + d)(x) > 0 H(i, d)(x) = 0，其他情况

把这个逐记录规则命名为快照算子 H。由推导可直接得到：

H(i,d) = distinct(i+d) − distinct(i)
i(x)(i+d)(x)H(i,d)(x)含义

≤ 0≤ 00前后都不在 distinct 输出中

这与第 1 节一致：t = 2 是 1→2，H 输出 0；t = 3 是 2→1，H 输出 0；t = 4 是 1→0，H 输出 −1。

4. H 需要旧权重：由此得到增量电路

第 3 节已经得到单批规则 H(i,d)，但变化流只直接提供当前批 d[t]。还需要从历史变化中恢复 H 所需的本批前旧快照。

令 d 是输入变化流，并定义：

s = ℐ(d)

对任意逻辑时刻 t，s[t] 是累积到本批结束后的输入快照；应用 d[t] 前的旧快照就是 s[t−1]（即 z⁻¹(s)[t]），也就是 H 的第一个实参。约定 s[−1]=0，因此 t = 0 时延迟输出为零元；相应地 distinct(s[−1])=0。于是每一批都能计算 H(s[t−1],d[t])：

ASCII 电路对照
d ──→ ℐ ──→ z⁻¹ ──→ s[t−1] ──┐ ├─→ ↑H ──→ 输出变化流 d ────────────────────────────┘

因此 DBSP 论文 Proposition 4.7 的电路形式为：

(↑distinct)Δ(d) = (↑H)(z⁻¹(ℐ(d)), d)

4.1 证明电路与朴素增量定义逐时刻相等

沿用第 4 节的 s=ℐ(d)，令 y=↑distinct(s)，即每批结束后的完整 distinct 结果流；约定 y[−1]=distinct(s[−1])=0。对任意逻辑时刻 t：

(𝒟 ∘ ↑distinct ∘ ℐ)(d)[t] = 𝒟(y)[t] // s=ℐ(d)，y=↑distinct(s) = y[t] − y[t−1] // 𝒟 的定义 = distinct(s[t]) − distinct(s[t−1]) // ↑distinct 的定义 = distinct(s[t−1]+d[t]) − distinct(s[t−1]) // s[t]=s[t−1]+d[t] = H(s[t−1],d[t]) // H 的定义：第一实参取本批前快照 s[t−1] = (↑H)(z⁻¹(ℐ(d)), d)[t] // z⁻¹(ℐ(d))[t]=s[t−1]，↑H 按时刻作用

两端对任意输入变化流 d 与任意逻辑时刻 t 的输出相同，因此朴素形式与 Proposition 4.7 电路定义的是同一个增量流算子：

朴素形式

(↑distinct)Δ = 𝒟 ∘ ↑distinct ∘ ℐ：定义每批输出必须等于新旧完整 distinct 结果之差。

高效形式

(↑distinct)Δ(d) = (↑H)(z⁻¹(ℐ(d)),d)：保存旧权重，只检查本批受影响记录是否跨越 0。

5. 实现顺序与适用范围

每一批对受影响记录 x 按固定顺序执行：

1. old ← 状态中保存的 Xt−1(x) 2. new ← old + dt(x) 3. 输出 H 给出的权重变化（0 则不发射） 4. 把状态中的计数更新为 new

必须先读旧计数、再算输出、最后提交新状态。若先更新再读，old 与 new 会变成同一个值，边界穿越会被吞掉。

同批内同一记录的多次变化先在 Z-set 中合并为净权重，再做一次 old→new 判断。distinct 比较的是批边界前后的状态，不是批内语句的临时顺序。

只有 d 中出现的记录，其权重才可能改变。因此每批检测工作的规模由 |d| 界定；但为了读取 old，状态仍需保存当前关系中每条记录的完整权重。
边界：Z-set 上的 distinct 不保持加法，不能用 (↑O)Δ = ↑O，也不是双线性三项。计算量与本批变化成正比，但状态须保存输入中所有非零权重记录，而非仅输出的正权重记录。

6. 小结

  1. distinct 把正权重压成 1；相同变化是否改变输出，取决于应用变化前的权重。
  2. 从 ΔV=distinct(i+d)−distinct(i) 可直接推出 H：只有权重跨越 ≤0 与 >0 的边界时才输出 ±1。
  3. H 需要旧输入，因此用 z⁻¹(ℐ(d)) 提供每批开始前的状态，得到 Proposition 4.7 的电路。
  4. 高效电路与朴素增量定义相等；它避免重算完整 distinct，但仍需保存完整输入权重。
