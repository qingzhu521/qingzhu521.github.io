四个原语：流上的基本运算

教程制作 · 李金懋（OceanBase）

本课定义 DBSP 的四个流原语：Lift ↑、Delay z⁻¹、Integration ℐ 和 Differentiation 𝒟。它们分别处理逐时刻计算、历史状态、变化累积和快照差分。

依据： DBSP §2–§3 Streams and operators · arXiv:2203.16684

1. 输入对象：Z-set 流

四个原语处理的对象不是单张表，而是按逻辑时间排列的 Z-set 流。以下直接使用已定义的快照流 s 与变化流 Δ。

流 s：时间 t = 0, 1, 2, … → 值 s[t] 流中每个时间步的值类型都是 Z-set
四个原语都是 流 → 流 的变换：输入一条流，输出另一条流。下面用订单表示例逐个定义它们。

2. 原语 ① Lift ↑ ：由快照算子定义流算子

定义：给定一个处理单个快照的算子 f，Lift 定义相应的流算子。对任意逻辑时刻 t，它只将 f 应用于该时刻的输入快照。

示例表：表是 orders(id, amount)。 缩写 A:10 = 整行 (id=A, amount=10)； amount 就是订单金额这一列，不是新概念，也不是 Z-set 的权重。 记录权重写为 ↦1（出现次数）。
给定快照算子 f : ℤ[A] → ℤ[B]。对任意逻辑时刻 t： (↑f)(s)[t] = f(s[t]) // 输出流在时刻 t 的值 = 把 f 应用于输入流在同一时刻 t 的值 // 不读取 s[t−1]、s[t+1] 或任何其他时刻的值 例：f = filter(amount ≥ 20) // 即 SQL: SELECT * FROM orders WHERE amount >= 20 // 只保留「金额 ≥ 20」的行；A:10 的 amount=10 被滤掉 s[1] = {A:10↦1, B:20↦1} → (↑f)(s)[1] = {B:20↦1} s[2] = {A:10↦1, B:20↦1, C:30↦1} → {B:20↦1, C:30↦1} s[3] = {A:10↦1, C:30↦1} → {C:30↦1} s[4] = {A:25↦1, C:30↦1} → {A:25↦1, C:30↦1} // A:25 已跨过阈值，进入输出

它会什么

  • 把 SQL 算子变成「流上的算子」
  • 无状态：当前输出只看当前输入
  • 复合干净：↑(g∘f) = ↑g ∘ ↑f（见下）

它不会什么

  • 记不住上一时刻（没有记忆）
  • 不会做「累计」或「差分」
  • 单独用它，没法从变化重建快照
符号速读：∘ = 函数复合（先内后外），(g∘f)(x) = g(f(x))。
↑(g∘f) = ↑g ∘ ↑f：先合成再 lift = 先 lift 再串联，故 filter → project 可逐个 lift。
Lift 的时间语义：对任意时刻 t，输出只读取同一时刻的输入 s[t]。它把普通查询嵌入流电路，但本身不保存历史、也不解决增量。

3. 原语 ② Delay z⁻¹ ：记住上一步

人话：输出比输入晚一个时间步。t=0 吐零元（空 Z-set）；t≥1 吐「上一时刻的输入」。

s = [ s₀, s₁, s₂, s₃, s₄, ... ] z⁻¹(s) = [ 0, s₀, s₁, s₂, s₃, ... ] 使用订单快照（从 t=1 起写，t=0 为空）： s : t₀=∅ | t₁={A10,B20} | t₂={A10,B20,C30} | t₃={A10,C30} | t₄={A25,C30} z⁻¹(s): t₀=∅ | t₁=∅ | t₂={A10,B20} | t₃={A10,B20,C30}| t₄={A10,C30}
ts[t]（快照）z⁻¹(s)[t]读法
0 ∅ ∅ 约定：初始延迟输出 0
1 {A10↦1, B20↦1} ∅ 「上一时刻」还是空
2 {A10↦1, B20↦1, C30↦1} {A10↦1, B20↦1} 吐出 t=1 的快照
3 {A10↦1, C30↦1} {A10↦1, B20↦1, C30↦1} 吐出 t=2 的快照
4 {A25↦1, C30↦1} {A10↦1, C30↦1} 吐出 t=3 的快照
工程直觉：z⁻¹ 就是一枚寄存器 / 上一版本快照缓存。 任何需要读取上一时刻输入的流算子，都可以通过 z⁻¹ 获得该值。 它是 DBSP 里唯一的状态原语。

记号来自 DSP 的 Z 变换：乘以 z⁻¹ 表示延迟一个样本。这里不依赖 Z 变换知识，只需按“晚一步”理解。

4. 原语 ③ Integration ℐ ：变化流 → 快照流

人话：把到目前为止的所有变化累加起来，得到当前完整表。它就是流上的前缀和。

ℐ(Δ)[t] = Δ[0] + Δ[1] + … + Δ[t] = Σi=0..t Δ[i] // Z-set 加法：逐 key 加权重

边界：t=0 也是真实的第一个样本。初始变化 d0 负责产生初始快照；从空库开始时通常 d0=∅。

用手算过的 Δ 走一遍

tΔ[t]（变化）ℐ(Δ)[t] = 累计和（快照）
0 ∅ ∅
1 {A10↦1, B20↦1} {A10↦1, B20↦1}
2 {C30↦1} {A10↦1, B20↦1, C30↦1}
3 {B20↦−1} {A10↦1, C30↦1}
4 {A10↦−1} + {A25↦1} {A25↦1, C30↦1}
实现上不必每次从 t=0 重加：用递推 ℐ(Δ)[t] = ℐ(Δ)[t−1] + Δ[t]， 而 ℐ(Δ)[t−1] 恰好可以用 z⁻¹ 存住。 所以积分内部就藏着一枚 delay。
令 s = ℐ(Δ)，即积分输出的快照流。 ℐ(Δ) = fix α. (Δ + z⁻¹(α))
ASCII 反馈电路对照
Δ ──→ (+) ──→ s ↑ │ └─ z⁻¹(s) ─┘ 反馈支路中的 z⁻¹(s) 与后文的 z⁻¹(s) 是同一个对象： 它是输出快照流 s 延迟一个时间步后的流。 因此，对任意 t： s[t] = Δ[t] + z⁻¹(s)[t] = Δ[t] + s[t−1] // t ≥ 1 并且 s[0] = Δ[0]，因为 z⁻¹(s)[0] = 0。

5. 原语 ④ Differentiation 𝒟 ：快照流 → 变化流

人话：相邻快照相减。即“本时刻快照减去上一时刻快照”。

𝒟(s)[0] = s[0] 𝒟(s)[t] = s[t] − s[t−1] // t > 0 = s[t] + (− s[t−1]) // Z-set 减法

而 s[t−1] 就是 z⁻¹(s)[t]，所以：

𝒟(s) = s − z⁻¹(s) // 每个时刻：当前快照减去「延迟后的快照」

从快照反推变化

ts[t]z⁻¹(s)[t]𝒟(s)[t] = s − z⁻¹(s)
0 ∅ ∅ ∅
1 {A10,B20} ∅ {A10↦1, B20↦1}
2 {A10,B20,C30} {A10,B20} {C30↦1}
3 {A10,C30} {A10,B20,C30} {B20↦−1}
4 {A25,C30} {A10,C30} {A10↦−1} + {A25↦1}
和原变化流逐项相同。符号 𝒟 只是给「相邻快照相减」起了个名字。

6. 最重要的等式：ℐ 与 𝒟 互逆

对任意变化流 Δ： 𝒟(ℐ(Δ)) = Δ // 先把变化累加成快照，再做相邻快照之差，得到原来的变化流 Δ 对任意快照流 s： ℐ(𝒟(s)) = s // 先做相邻快照之差，再把这些变化累加，得到原来的快照流 s 采用定义 𝒟(s)[0] = s[0]，因此 t=0 的边界已包含在算子定义中。
逐行验证 𝒟(ℐ(Δ)) = Δ： t = 0: 𝒟(ℐ(Δ))[0] = ℐ(Δ)[0] = Δ[0] t > 0: 𝒟(ℐ(Δ))[t] = (Δ[0]+...+Δ[t]) − (Δ[0]+...+Δ[t−1]) = Δ[t] 逐行验证 ℐ(𝒟(s)) = s： ℐ(𝒟(s))[t] = s[0] + (s[1]−s[0]) + ... + (s[t]−s[t−1]) = s[t] // 中间项两两抵消

7. 四件套对照卡

符号名字人话有状态？你已经会的操作
↑f Lift 每个时刻各自跑 f 否 filter / project 套在整条流上
z⁻¹ Delay 输出 = 上一时刻输入 是（唯一状态原语） 缓存上一版快照
ℐ Integration 变化累加 → 快照 是（内含 z⁻¹） 前缀和
𝒟 Differentiation 快照差分 → 变化 是（内含 z⁻¹） 相邻相减

8. 小结

  • ↑f 逐时刻套普通算子，无记忆
  • z⁻¹ 晚一步 = 上一版缓存，唯一状态原语
  • ℐ 变化累加 → 快照（前缀和）
  • 𝒟 快照差分 → 变化（s − z⁻¹(s)）
  • 𝒟(ℐ(Δ)) = Δ；ℐ(𝒟(s)) = s → 两种流表示可相互还原
